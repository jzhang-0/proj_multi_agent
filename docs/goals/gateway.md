# IM 网关(GATE)— 远期

把手机上的群聊(IM)接到同一条总线:人在群里 @ 成员等价于本机 `./msg`,成员的发言回传群里署名显示。**IM 平台选型是人的决策,未拍板前本卷不开工**(候选:飞书 / Discord / 自建;Telegram 已排除——bot 看不到其他 bot 的消息)。

- [ ] **GATE-001** — 网关抽象:`src/gateway/` 定义 adapter 接口(收群消息 → 入队 bus;订阅 bus → 发回群),与具体 IM 解耦;单 bot 模式(网关解析 @ 路由、代发署名),不要求每成员一个 bot 账号。
  - 前置:BUS-008;人拍板 IM 平台。
- [ ] **GATE-002** — 第一个 adapter 实现(平台按人拍板结果),含凭证配置方式与断线重连。
  - 前置:GATE-001。
- [ ] **GATE-003** — 端到端:手机群里 @ 成员派活、成员间协作、结果回到群里,全程不碰电脑实测一遍。
  - 前置:GATE-002、ROS-003。
- [ ] **GATE-004** — 网关安全:只服务白名单群与白名单用户;来自 IM 的消息标记来源(`from` 带 `im:` 前缀或等价机制)并同样过清洗与限频;危险操作指令即使来自 IM 的 human 也要求本机二次确认(远程指令弱于本机指令)。
  - 前置:GATE-002。
